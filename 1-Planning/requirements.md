# Requirements: BookIt (MVP)

| ID | User story | Acceptance criteria |
|---|---|---|
| US-01 | As a customer, I can browse providers and see free slots | Only future, unbooked slots are shown |
| US-02 | As a customer, I can book a slot | A slot can never be double-booked; confirmation is shown |
| US-03 | As a customer, I can cancel a booking | Allowed until 2 hours before the slot; the slot becomes free again |
| US-04 | As a provider, I can set weekly availability | Recurring weekly hours plus one-off days off |
| US-05 | As a provider, I can see today's bookings | Sorted by time, with the customer's name and contact |
